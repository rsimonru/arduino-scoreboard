# Scoreboard

Aplicación para marcador deportivo.

## Description

Esta aplicación implementa un marcador electrónico deportivo, adaptado a varios deportes (fútbol, fútbol sala y baloncesto).

Permite la personalización de los nombres de los equipos local y visitante, así como la carga de los escudos asociados a cada club.

## Requisitos hardware y software

### Hardware

- Arduino UNO Q (x1)
- cable USB-C® (para alimentación y programación) (x1)
